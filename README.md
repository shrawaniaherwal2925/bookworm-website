 📚 BookWorm

A full-stack web application that allows users to explore and access books using open-source APIs and publicly available digital libraries.

---

 Features

* 📱 Responsive Design (works on mobile + desktop)
* 🔍 Search and browse books
* 📖 View book details and access PDFs
* ⚡ Dynamic navigation using JavaScript
* 🌐 API-based data fetching

---

 Tech Stack

**Frontend:**

* HTML
* CSS
* JavaScript

**Backend:**

* Node.js
* Express.js

**Database:**

* MySQL


 **Note (Important)**

This project uses book metadata and PDF links sourced from publicly available digital libraries.
All rights belong to the original content providers.
